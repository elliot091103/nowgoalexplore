Extract all data flow

1. Extract league, season
2. Extract team, league full name, schedule, standings, team season tech (use league id and season from 1)
https://football.nowgoal.net/jsData/matchResult/json/{season}/{c / s depend on the league type}{league_id}_en.json
2.1 Extract player season tech from this url
https://football.nowgoal.net/jsData/Count/json/{season}/playerTech_{league_id}_en.json (use league id and season from 1)
3. Extract player general info (transfer, basic info, total stats) from this url
	https://football.nowgoal.net/jsData/playerInfo/player{player_id}_en.json (use player_ids from 2)
4. Extract team info from this url
https://football.nowgoal.net/jsdata/teamInfo/teamdetail/json/tdl{team_id}_en.json (use team id from 2)
5. Extract team transfer history from this url
https://football.nowgoal.net/ajax/GetTeamTransferByYear?teamId={team_id}&year={season} (use the team id from 2, and TransferSeason from 4, any player id from transfer data that not exist yet will be extract using the url at 3)
6. Extract player match tech stats from this url 
https://www.nowgoal.net/Ajax/SoccerAjax?type=18&id={match_id} (match_id from schedule of 2, only get if the match is already played)
7. Extract team tech stat, match event and key event, line up will need to extract from raw html
https://www.nowgoal.net/match/live-3061002
8. Extract detail odd movement from this url (match id from schedule of 2, other params will be check as the dict below, only extract if game already played)

https://www.nowgoal.net/ajax/soccerajax?type=14&=&id={match_id}&t={odd_type}&cid={bookmaker_id}&h={is_halftime}&r1=0&r2=0&r3=0&flesh=0.8322862800944925
